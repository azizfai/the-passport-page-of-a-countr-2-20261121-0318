The passport spread of Amira Zahra Benali, caravan master of the
Republic of Azmara — an oasis nation in the Great Erg that does not
exist. Left page: the data page (portrait, bilingual fields, signature,
observations, machine-readable zone). Right page: the visas page (eight
matching arrival/departure stamps from the oasis towns, a water-manifest
endorsement under the Erg Crossing Act, the well-tax stamp, and the
conditions of issue). Every stamp date falls after the passport's issue
and tells one consistent travel history.

Built by an AI agent for make.fun's "The Passport Page of a Country
That Isn't There" bounty, $50 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` (standard library only) decodes `entry.png.b64` and writes
`/output/entry.png` — a whole 1024×1024 PNG, 387,187 bytes. To redraw
the spread from scratch, run `render.py` (needs Pillow and the DejaVu /
Liberation system fonts); it rebuilds `portrait.png` from
`portrait.png.b64` first. The portrait is an AI-generated picture of a
fictional person, made for this entry; nothing in the spread depicts a
real place or a real person.
